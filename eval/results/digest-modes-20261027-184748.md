### p04 · Direct Pass@$k$ Optimization for Thought Pruning: Balancing Quality and Diversity in Test-Time Reasoning

The paper optimizes pass@k directly when pruning partial reasoning solutions at test time, balancing quality and diversity within a single objective instead of ad-hoc scoring. It outperforms quality-based and diversity-based pruning across eight open-weight reasoning models, especially when keeping a moderate number of candidates.

- Source: arXiv · [https://arxiv.org/abs/2610.31667v1](https://arxiv.org/abs/2610.31667v1) · 2026-10-22
- Why you see this: Interest match (AI agents): Advances evaluation/selection methods for reasoning agents, matching the agent benchmarks and evaluation facet.

<a id="p08"></a>
### p08 · BrickWright: Agentic Creation of Physically Feasible Brick Builds

BrickWright is a framework guiding pretrained coding agents to generate physically feasible LEGO builds from text/image prompts, using the BrickLayer Python assembly API plus a physical-validity validator with feedback. Guided agents reach 100% physical validity on 512 prompts versus 9-69% for baselines, and beat specialized text-to-brick models. This appears to be the original BrickWright paper, not a repeat.

- Source: arXiv · [https://arxiv.org/abs/2610.31651v1](https://arxiv.org/abs/2610.31651v1) · 2026-10-22
- Why you see this: Interest match (AI agents): Directly shows tool-equipped coding agents solving a physical 3D assembly task, bridging the agent frameworks and 3D generation interests.

<a id="p01"></a>
### p01 · A Unified Framework for Image-to-3D Part Generation via Variable Granularity

FlexPart is a unified image-to-3D part generation framework accepting variable-granularity geometric conditions (points, boxes, masks) via gated adaptive modulation and asymmetric geometric guidance. On PartVerseXL with mask conditioning it cuts Part CD by 16.6% vs TripoSG+SAM3D and 10.5% vs OmniPart. This looks like the previously covered FlexPart work rather than a new paper.

- Source: arXiv · [https://arxiv.org/abs/2610.31671v1](https://arxiv.org/abs/2610.31671v1) · 2026-10-22
- Why you see this: Interest match (3D generation): Controllable image-to-3D part generation is squarely in the 3D generation interest, but likely a repeat of prior coverage.

<a id="p05"></a>
### p05 · SpectralCanary: Embarrassingly Simple Low-Frequency Traces for T2I Dataset-Use Auditing

SpectralCanary is a proactive T2I dataset-use auditing method that blends a fixed canary image into every dataset image via a low-pass mask, then detects the transferred signal in suspect models' outputs. It achieves ~91-94% TPR@1% FPR across architectures and datasets while preserving image quality and resisting removal attacks.

- Source: arXiv · [https://arxiv.org/abs/2610.31659v1](https://arxiv.org/abs/2610.31659v1) · 2026-10-22
- Why you see this: Interest match (AI copyright policy): Dataset-use auditing is directly relevant to AI copyright policy concerns around training data provenance.
